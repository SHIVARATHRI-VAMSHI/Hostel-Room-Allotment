# Hostel Room Allotment System

## 📌 Project Overview
The **Hostel Room Allotment System** is a Java-based console application developed using Core Java. It helps manage hostel rooms, student details, and room allotments in an organized manner.

## 🎯 Objectives
- Manage student information.
- Maintain hostel room details.
- Allocate rooms to students.
- Track room allotment status.
- Store application data using file handling.

## 🛠️ Technologies Used
- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Storage:** File Handling
- **IDE:** Eclipse
- **Version Control:** Git and GitHub

## ▶️ How to Run
1. Clone or download this repository.
2. Open Eclipse IDE.
3. Import the project into your workspace.
4. Ensure the Java configuration is set correctly.
5. Open `Main.java` inside the `com.main` package.
6. Run the program as a Java Application.
